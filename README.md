# IntelliShop AI

IntelliShop AI is an AI-powered e-commerce platform built to demonstrate backend engineering and AI engineering concepts.

## Tech Stack

### Backend
- FastAPI
- SQLAlchemy
- Pydantic
- Psycopg 3

### Database
- Supabase PostgreSQL

### Frontend
- Streamlit

### AI
Planned features include:
- Semantic product search
- RAG shopping assistant
- Product recommendations
- AI shopping agent
- Tool calling
- MCP integration

## Architecture

Streamlit
↓
FastAPI
↓
SQLAlchemy
↓
Psycopg 3
↓
Supabase PostgreSQL
